# 로컬 개선안

외부 번역 API 없이, Mac mini M2 16GB 기준으로 정리한 개선 목록입니다.

| 번호 | 항목 | 상태 |
|------|------|------|
| 1 | STT `--context` + 용어집 연동 | 예정 |
| 2 | STT JSON 보관 + 재정리·재번역 | **적용** |
| 3 | Ollama 자동 unload | **적용** |
| 4 | NLLB 용어집·번역 캐시 | 예정 |
| 5 | hybrid 초안 체크포인트·재개 | **적용** |
| 6 | GUI 대기열 + 자막 미리보기 | **적용** |
| 7 | 화자 구분(`--diarize`) → 문맥 | 예정 |
| 8 | 여러 자막에서 용어집 만들기 | **적용** |

## 1. STT `--context` + 용어집 연동 (예정)

mlx-qwen3-asr의 `--context`에 인물명·고유명사를 넘기면 인식 단계에서 오류가 줄어듭니다. `glossary.txt` 원문 쪽을 힌트로 쓰거나 별도 `asr_context.txt`를 두는 방식이 가능합니다.

## 2. STT JSON 보관 + 재정리·재번역 (**적용**)

음성 인식 결과를 `result/{파일명}.asr.json`에 남깁니다. 같은 영상은 STT를 다시 돌리지 않고 정리·번역만 반복할 수 있습니다.

- 터미널: `./run.sh result/파일.asr.json --mode reclean --lang ja`
- GUI: 저장 폴더에 `.asr.json`이 있으면 **저장된 음성 인식 결과 재사용** 체크박스가 나타납니다.

## 3. Ollama 자동 unload (**적용**)

Ollama/hybrid 번역이 끝나면 `ollama stop`으로 모델을 내려, 다음에 음성 인식이 느려지지 않게 합니다. 실패·교정 건너뛰기 직후에도 호출합니다.

## 4. NLLB 용어집·번역 캐시 (예정)

용어집은 지금 Ollama 경로에만 있습니다. NLLB 전용 치환·검증과 `(언어, 원문) → 한국어` 디스크 캐시를 붙이면 시리즈·반복 대사에서 이득이 큽니다.

## 5. hybrid 초안 체크포인트·재개 (**적용**)

NLLB 초안을 `{원본stem}_hybrid_draft.json`에 남기고, 교정이 끝난 뒤에만 지웁니다. 중간에 취소해도 초안이 남습니다.

```bash
# 초안만 다시 교정
./run.sh result/파일.srt --mode translate --engine hybrid --lang ja \
  --resume-draft result/파일_hybrid_draft.json
```

GUI에서는 NLLB+교정 선택 시 초안 파일이 있으면 **초안만 이어서 교정** 버튼이 나타납니다.

## 6. GUI 대기열 + 자막 미리보기 (**적용**)

- 파일을 여러 개 넣으면 같은 옵션으로 순차 처리합니다.
- 완료 후 **자막 미리보기**로 원문·한글을 나란히 볼 수 있습니다.

## 7. 화자 구분 → 문맥 (예정)

`--diarize`로 화자 구간을 받아 Ollama 문맥·호칭에 반영합니다. 의존성·메모리 부담이 있어 선택 옵션으로 두는 편이 맞습니다.

## 8. 여러 자막에서 용어집 만들기 (**적용**)

같은 분야·시리즈 영상은 인물명·호칭·고유명사가 파일마다 다르게 번역되기 쉽습니다. `원문.srt` + `원문_KOR.srt` 여러 쌍을 모아 후보를 고르고 `glossary.txt`에 저장합니다.

### 사용

- GUI: 상단 **용어집 만들기**, 또는 번역 완료 후 결과 카드의 같은 버튼
  1. 폴더/파일로 자막 쌍 추가 → **후보 찾기**
  2. 번역이 갈라진 항목(주황)을 확인하고, 등장 문장을 더블클릭하거나 번역을 직접 수정
  3. 체크한 뒤 **선택한 용어 저장**
- CLI: `venv/bin/python glossary_builder.py result/ --lang ja`

### 4번·1번과의 관계

- **4(NLLB 용어집·캐시)** 와 맞물리면 이 용어집이 빠른 NLLB 경로에도 쓰입니다.
- **1(STT `--context`)** 에는 확정된 원문 쪽만 넘겨 인식 힌트로 쓸 수 있습니다.

## 우선순위 메모

16GB에서는 2 → 3 → 5가 체감이 크고, 6·**8**은 여러 영상을 같은 분야로 돌릴 때 편합니다. 1·4는 8에서 만든 용어집을 파이프라인 전 구간에 퍼뜨리는 작업이고, 7은 멀티 화자일 때입니다.
